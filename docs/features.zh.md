# 特性文档

[English](features.md) | **简体中文**


照片共享应用程序中所有功能的综合指南。

## 核心特点

### 📸 活动管理

将照片组织成具有丰富元数据的离散活动。

**关键能力：**

- 使用自定义 slugs 创建无限活动
- 设置活动日期、地点和描述
- GPS 具有自动反向地理编码的坐标
- 公共或私人可见性控制
- 可选密码保护
- 标记活动以便于发现

**管理后台：**

- 创建/编辑/删除活动
- 批量照片上传
- 活动分析
- 协作者管理

**使用案例：**

- 婚纱照图库
- 生日聚会专辑
- 假期照片集
- 企业活动文档
- 家庭团聚图库

### 🖼️ 照片上传和管理

先进的照片上传系统，自动处理。

**上传功能：**

- 拖放界面
- 多文件选择
- 带有进度跟踪的上传队列
- 重试失败的上传
- 客户端图像预览生成
- EXIF 数据提取
- GPS 位置提取
- 占位符的 Blurhash 生成

**图像处理：**

- **原始**：保留完整分辨率（包括RAW文件，以其原始格式保存）
- **预览**：客户端生成的JPEG，最长边最大1920px，85%质量
- 不应用服务器端水印、调整大小或 Instagram 风格的方形裁剪 — 两者均适用
上述衍生品完全是在上传时在客户端生成的（请参阅
[图像处理.md](./image-processing.zh.md))

**支持的格式：**

- JPEG（.jpg、.jpeg）
- PNG (.png)
- HEIC (.heic) - iOS 照片
- WebP (.webp)
- RAW 格式（.cr2、.nef、.arw、.dng 和其他 libraw 支持的格式） - 通过 `libraw-wasm` 解码客户端以生成 JPEG 预览；原始 RAW 文件按原样保留
- 视频（.mp4、.mov）- 保留原始文件，定时维护任务可以生成 1080p H.264 播放衍生文件和封面帧

**保留元数据：**

- 相机品牌/型号
- ISO、光圈、快门速度
- 焦距
- 捕获时间戳
- GPS坐标
- 图片尺寸

### ✂️ 图像和视频编辑

之前或之后直接在浏览器（以及本机 Android 应用程序）中编辑照片和视频
上传，无需外部软件。

**图像编辑**（由 `react-filerobot-image-editor` + `react-konva` 提供支持）：

- 裁剪和旋转
- 曲线和水平调整
- 保存回活动，替换 R2 中的原始和/或预览

**视频编辑**（由`@ffmpeg/ffmpeg`提供支持，完全在客户端运行WASM）：

- 修剪开始/结束
- 裁剪和旋转
- 播放速度调整
- 使用单线程FFmpeg核心，因此不需要跨源隔离（COOP/COEP）标头

**本机注意事项：**

- 在本机 Android 上，在编辑之前将媒体作为同源 blob 获取，以避免画布污染
WebView 中跨源图像加载的问题
- Android WebView 中的多部分`FormData` 上传不可靠，因此“替换已编辑的照片”
端点在本机上接受原始 `application/octet-stream` 主体（具有遗留的多部分回退
对于网络）

### 🌐 多语言

Web 应用支持在运行时切换英文 (`en`) 和简体中文 (`zh-CN`)。登录后可从用户菜单或设置中选择语言。

- 语言切换后，已经完成本地化的页面会立即重新渲染，无需刷新
- 选择结果保存在 local storage 的 `photos.language` 中
- 尚未保存偏好时使用浏览器语言
- 已本地化页面中的日期和数字使用当前语言区域格式
- 翻译资源按功能放在 `apps/web/src/i18n/locales/<locale>/` 下

主导航、图库、上传、账户、协作以及部分管理流程已经完成本地化。少量旧管理页面、编辑器页面和法律说明页面仍在从硬编码英文迁移。

### 🧠 AI 支持的搜索和组织

**状态：** 仅免费套餐（Cloudflare Workers AI，每天约 10,000 个神经元，免费）

- **统一搜索** (`/search`)：匹配文件名、城市/位置和人工智能生成的照片
通过 SQLite FTS5 提供的标题，可以选择根据语义相似度重新排序（之间的余弦相似度）
搜索查询的嵌入和每张照片存储的嵌入）
- **AI 字幕**：Workers AI 视觉模型 (`@cf/llava-hf/llava-1.5-7b-hf`) 生成一个简短的字幕
每张照片的描述，由批量限制的每小时 cron 作业逐渐生成（从来没有
每次上传调用，以保持在每日免费分配范围内）
- **人物**：在上传时检测并完全在客户端嵌入面部
（`@vladmandic/human` — MediaPipe BlazeFace 检测器 + FaceRes 描述模型，选择
face-api.js 可以更好地回忆体育摄影中常见的角度/动作镜头脸部，
因为 Workers AI 没有人脸嵌入模型），然后按每小时分组为人员集群
服务器端聚类工作（纯向量数学，没有人工智能调用——使用人类自己记录的
距离/相似度公式）。管理员可以命名、合并和删除人员组，地址为
`/admin/people`。到目前为止，只有一张照片的组在默认视图中是隐藏的（通常
只是一个还没有聚集第二张照片的人）； a》展示N张单张照片
groups”切换按需显示它们，空状态区分“尚未检测到任何内容”
从“找到的组中，它们现在只是单张照片”。之前上传的照片
现有的功能可以通过同一页面上的“扫描面部库”操作来回填 -
检测必须在浏览器中运行，因此这是客户端驱动的扫描（带有进度/取消）
而不是服务器 cron。每个集群运行都会处理一小批 CPU 预算自适应批次
faces — Cloudflare 的 Workers Free 计划硬上限 CPU 每个请求/cron 触发器 10 毫秒的时间（不是
挂钟时间），并且一次相似性比较成本`O(embedding dimensions)`（1024个浮动-
点操作，而不是 O(1))，因此一张脸只与（最多 300 个）最-
建立现有的人——而不是整个图书馆——之间有一个真正的挂钟守卫
面孔作为后盾，因此无论有多少不同的人，成本都不会无限制地增长
被认可。同一页面上的“立即集群”按钮可让管理员立即触发此操作
并重复（循环许多小调用到`POST /admin/people/cluster-now`客户端，直到
积压已耗尽）而不是等待下一个每小时的 cron 滴答
- **合并建议**：因为聚类只会将新面孔与前 300 名进行比较
最成熟的人（见上文），两个集群可以真正是同一个人，而不需要
聚类有机会注意到。上的“查找合并建议”按钮
`/admin/people` 对每个人进行单独、完整的 `O(clusterCount²)` 成对扫描
（不限于前 N 个子集，因为这里的目标是彻底性而不是快速
每次上传决定）通过`GET /admin/people/merge-suggestions`，可通过光标恢复
许多小的CPU安全步骤，就像聚类本身一样——受*确定性的限制
维度操作*预算而不是挂钟计时器，因为此扫描的比较循环
其中没有 I/O，并且 Cloudflare Workers 在同步期间故意冻结 `Date.now()`
执行（Spectre 计时缓解），这将使基于计时器的防护成为静默无操作
这里。每次比较也会在数学上确定一对不能进行比较时提前退出
匹配，让一个调用检查比天真的总是检查所有 1024 维更多的对
方法可以。建议故意使用比自动“更低”的相似度栏
聚类（因为每个建议在合并之前都会经过手动审核，与自动聚类不同）
- 如果仍然没有找到任何内容，搜索会自动重试一次，范围更广
放弃之前的门槛，因为这个应用程序的动作运动照片（头盔/护目镜/奇怪的角度）
对于真正匹配的面孔，甚至可以合理地低于正常的“同一人”标准。
匹配项与一键合并（或忽略）的相似度分数并排显示
- **将某人链接到帐户**：在某人的详细信息页面（`/admin/people/:id`）上，管理员
最多可以搜索现有用户帐户并将其链接到该人员集群（通过电子邮件）
每人一个帐户（通过部分唯一索引强制执行）
`person_clusters.linked_user_email`）。链接后，该帐户会看到“只有我”过滤器切换
时间线标题 (`GET /api/me/photos`) 旁边，它将网格过滤为仅显示照片
包含他们的脸。管理员赋予某人的全名仅限管理员 - 切换标签
其过滤视图仅使用他们的名字（参见 `utils.ts` 的 `firstNameOf()`），从不
全名

## 限制和已知问题

**当前限制：**

- 没有自适应码率视频流；维护任务最多生成一个 1080p H.264 衍生文件
- 每个 R2 上传最大 5GB（分段）
- D1 数据库：最大大小 1GB
- 没有打包的 iOS 应用程序（仅限 Android 本机应用程序；Web 应用程序本身可以在 iOS Safari 中运行）

**已知问题：**

- HEIC 在某些 Android 浏览器上上传
- Safari 模糊占位符渲染怪癖
- 某些位置的地理编码速度较慢

**解决方法：**

- 上传前将HEIC转换为JPEG
- 使用 Chrome 以获得最佳兼容性
- 如果地理编码失败，请手动设置位置

请参阅 GitHub Issues 了解完整的错误列表和状态。

## FAQ

**问：我可以存储多少张照片？**
答：R2 存储空间是无限的。 D1 数据库在达到 1GB 限制之前可以容纳约 100 万张照片。

**问：我可以自定义外观吗？**
答：是的！编辑 Tailwind 配置，上传自定义徽标，在环境变量中设置品牌名称。

**问：这真的是开源的吗？**
答：是的，完全开源。检查LICENSE文件了解详细信息。

**问：我可以在没有 Cloudflare 的情况下运行它吗？**
答：不容易。它专为 Cloudflare Workers + D1 + R2 设计。

**问：运行需要多少钱？**
答：Cloudflare 免费套餐每月涵盖约 10 万张照片。付费计划起价为 5 美元/月。

**问：我可以从 Google Photos 迁移吗？**
答：还没有。迁移工具计划在未来发布。

**问：有托管版本吗？**
答：不是正式的。这是自托管软件。
